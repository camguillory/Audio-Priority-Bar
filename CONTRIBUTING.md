# Contributing

Thanks for helping improve Audio Priority Bar.

Please read the [contribution guide](README.md#contributing) before starting.
In short:

1. Open an issue first for a substantial change.
2. Fork the repository and branch from `develop`.
3. Open your pull request against `develop`, not `main`.

See [Build from source](README.md#build-from-source) to run the app locally.
CI tests every pull request automatically.
